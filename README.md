# Immoweb Property Scraper - Energy Certificate Branch

## Overview
This branch extends the original Immoweb scraper to include energy certification data for Belgian properties. The enhancement aims to improve property value analysis by incorporating energy efficiency metrics.

## Branch-Specific Changes

### New Files
- `Energy_scrape.py`: Standalone script for energy certificate extraction


### Key Features
- Energy certificate extraction from property listings
- Single property URL testing capability
- Batch processing of energy data
